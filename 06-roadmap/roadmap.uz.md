# Roadmap

Bu roadmap product-first, technology-second tamoyiliga asoslanadi.

## Phase 0 — Foundation
**Maqsad:** muammoni tushunish.

- birinchi user segmentni aniqlash;
- real userlar bilan interview;
- current workflowlarni xaritalash;
- alternativalarni o‘rganish;
- core problem hypothesisni test qilish;
- visionni yaxshilash.

**Natija:** validated problem definition.

## Phase 1 — Concept
**Maqsad:** systemni aniqlash.

- youth journey;
- core objects;
- MIYA roli;
- ecosystem modeli;
- trust va safety;
- first experience.

**Natija:** product specification.

## Phase 2 — Manual MVP
**Maqsad:** hammasini coding qilmasdan value'ni tekshirish.

Misollar:
- manual opportunity feed;
- community-based matching;
- manual team matching;
- MIYA challenge;
- project showcase;
- guided youth journey.

**Natija:** real user demand evidence.

## Phase 3 — First Product
Faqat 0–2 bosqichdan keyin:
- platformani tanlash;
- architecture;
- eng kichik foydali product;
- kichik user group;
- outcome measurement;
- iteration.

## Phase 4 — Ecosystem
- advanced opportunity discovery;
- team matching;
- mentor network;
- project workspace;
- verified achievements;
- AI assistance;
- organization partnerships;
- events va challenges.

## Phase 5 — Network

**Young people ↔ Projects ↔ Organizations ↔ Mentors ↔ Opportunities**

Bu bosqichda platforma oddiy appdan ko‘ra infrastructurega aylanishi mumkin.

## Qoida

Build qilish qiziqroq tuyulgani uchun Phase 0'dan Phase 3'ga sakramaymiz.
