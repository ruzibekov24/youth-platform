# User Problems

## Problem categories

### Discovery
I do not know what opportunities exist.

### Relevance
I see many opportunities, but do not know which are for me.

### Navigation
I found something interesting, but do not know what to do next.

### Learning
I need a skill before I can take action.

### Connection
I need people with skills or interests different from mine.

### Execution
I have an idea, but it never becomes a project.

### Feedback
I need someone to review my idea or work.

### Identity
I have done things, but my achievements are scattered.

### Continuity
I completed something, but there is no clear next step.

## Jobs-to-be-done hypotheses

When I discover an opportunity, I want to know whether it is relevant to me so I can decide whether to invest time.

When I have an idea, I want help turning it into a concrete next step so I can start.

When I need a team, I want complementary people with compatible goals so we can actually work together.

When I complete something, I want to document evidence of what I can do so future opportunities can recognize it.

When I return, I want a useful next action rather than simply more content.
