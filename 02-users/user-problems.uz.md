# User Problems

## Muammo kategoriyalari

### Discovery
Qanday imkoniyatlar borligini bilmayman.

### Relevance
Ko‘p imkoniyat ko‘raman, lekin qaysi biri menga mosligini bilmayman.

### Navigation
Qiziq narsani topdim, lekin keyingi qadamni bilmayman.

### Learning
Harakat qilishdan oldin skill kerak.

### Connection
Menga boshqa skillga ega odamlar kerak.

### Execution
Idea bor, lekin projectga aylanmaydi.

### Feedback
Idea yoki ishimni ko‘rib beradigan odam kerak.

### Identity
Qilgan ishlarim turli joylarda tarqalgan.

### Continuity
Bir ishni tugatdim, keyingi qadam nima ekanini bilmayman.
