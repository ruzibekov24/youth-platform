# Ecosystem

## Пять основных направлений

### 1. DISCOVER
Возможности, ресурсы, события, сообщества и проблемы.

Категории:
- Scholarships
- Competitions
- Exchange programs
- Volunteering
- Internships
- Grants
- Hackathons
- Olympiads
- Events
- Courses
- Mentorship

Вопрос не в количестве. Вопрос в том, как дать правильную возможность правильному человеку.

### 2. CREATE
Слой MIYA:
- сообщать о проблемах;
- развивать идеи;
- получать feedback;
- искать решения;
- создавать проекты.

### 3. CONNECT
Связывать людей вокруг целей:
- teammate matching;
- mentors;
- communities;
- organizations;
- collaborators.

### 4. BUILD
Лёгкая среда для превращения идеи в проект:
- project page;
- team;
- roles;
- roadmap;
- tasks;
- discussions;
- resources;
- milestones;
- evidence.

Не нужно превращать это в обычный project-management clone.

### 5. SHOW
Evidence-based youth profile:
- projects;
- achievements;
- skills;
- contributions;
- volunteering;
- events;
- certifications;
- publications;
- recommendations.

## Ecosystem loop

**Discover → Create → Connect → Build → Show → Discover**

Не каждый пользователь обязан использовать все направления.
