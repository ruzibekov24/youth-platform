# Ecosystem

## 5 ta dastlabki ustun

### 1. DISCOVER
Opportunity, resource, event, community va problem topish.

Kategoriyalar:
- Scholarship
- Competition
- Exchange
- Volunteering
- Internship
- Grant
- Hackathon
- Olympiad
- Event
- Course
- Mentorship

Savol: qancha opportunity borligi emas, **to‘g‘ri odamga to‘g‘risini qanday yetkazamiz?**

### 2. CREATE
MIYA layer:
- problem report;
- idea development;
- feedback;
- solution exploration;
- project creation.

### 3. CONNECT
Maqsad atrofida odamlarni bog‘lash:
- teammate matching;
- mentor;
- community;
- organization;
- collaborator.

### 4. BUILD
Idea'ni real projectga aylantirish:
- project page;
- team;
- roles;
- roadmap;
- tasks;
- discussion;
- resources;
- milestones;
- evidence.

Bu generic project-management clone bo‘lmasligi kerak.

### 5. SHOW
Evidence-based youth profile:
- projects;
- achievements;
- skills;
- contributions;
- volunteering;
- events;
- certifications;
- publications;
- recommendations.

## Ecosystem loop

**Discover → Create → Connect → Build → Show → Discover**

Hamma user barcha pillar'dan foydalanishi shart emas.
