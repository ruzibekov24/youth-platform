# Ecosystem

## Five initial pillars

### 1. DISCOVER
Find relevant opportunities, resources, events, communities, and problems.

Potential categories:
- Scholarships
- Competitions
- Exchange programs
- Volunteering
- Internships
- Grants
- Hackathons
- Olympiads
- Events
- Courses
- Mentorship

The question is not how many we list. It is how accurately we connect the right opportunity to the right person.

### 2. CREATE
The MIYA layer:
- report problems;
- develop ideas;
- ask for feedback;
- explore solutions;
- create projects.

### 3. CONNECT
Connect people around goals:
- teammate matching;
- mentors;
- communities;
- organizations;
- project collaborators.

### 4. BUILD
A lightweight environment for turning ideas into real projects:
- project page;
- team;
- roles;
- roadmap;
- tasks;
- discussions;
- resources;
- milestones;
- evidence.

This should not become a generic project-management clone.

### 5. SHOW
An evidence-based youth profile:
- projects;
- achievements;
- skills;
- contributions;
- volunteering;
- events;
- certifications;
- publications;
- recommendations.

## Ecosystem loop

**Discover → Create → Connect → Build → Show → Discover**

Not every user must use every pillar.
