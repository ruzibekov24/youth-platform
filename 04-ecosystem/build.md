# Build

## 🇺🇿 O‘zbekcha

Build — idea real ishga aylanadigan joy. Kelajakdagi project space'da goal, team, role, task, milestone, resource, discussion, progress, evidence va launch bo‘lishi mumkin.

> **Platforma projectning harakatlanishiga yordam berishi kerak.**

## 🇬🇧 English

Build is where ideas become real work. A future project space may include goals, teams, roles, tasks, milestones, resources, discussions, progress, evidence, and launch.

> **The platform should help projects move.**

## 🇷🇺 Русский

Build — место, где идеи превращаются в реальную работу. Проектное пространство может включать цели, команды, роли, задачи, этапы, ресурсы, обсуждения, прогресс, доказательства результата и запуск.
