# Create

## 🇺🇿 O‘zbekcha

Create — yoshning content iste’molchisidan **yaratuvchiga** o‘tadigan joyi.

MIYA: **Problem → Idea → People → Project → Action**

Project faqat startup emas: maktab tashabbusi, community yechimi, research, creative work, technology product, event, volunteering yoki educational resource bo‘lishi mumkin.

## 🇬🇧 English

Create is where a young person moves from consuming to **making**. MIYA powers **Problem → Idea → People → Project → Action**. A project can be a school initiative, research project, creative work, technology product, event, volunteer initiative, or community solution — not only a startup.

## 🇷🇺 Русский

Create — пространство перехода от потребления к **созданию**. MIYA: **Проблема → Идея → Люди → Проект → Действие**. Проектом может быть школьная инициатива, исследование, технология, мероприятие, волонтёрская или общественная инициатива — не только стартап.
