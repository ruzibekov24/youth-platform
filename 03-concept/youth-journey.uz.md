# Youth Journey

## Taklif qilinayotgan journey

### 1. Discover
Opportunity, resource, problem, event yoki community topiladi.

### 2. Understand
- Menga mosmi?
- Nega muhim?
- Nima kerak?
- Deadline qachon?
- Birinchi qadam nima?

### 3. Prepare
Kerakli skill va resurslar olinadi.

### 4. Connect
Peer, teammate, mentor, community yoki organization topiladi.

### 5. Create
Idea yoki problem bilan ishlanadi. Shu yerda MIYA muhim bo‘lishi mumkin.

### 6. Build
Idea real projectga aylanadi.

### 7. Launch
Natija submit, publish, present yoki real hayotga chiqariladi.

### 8. Show
Natija user profile'ida evidence sifatida ko‘rsatiladi.

### 9. Continue
Qilingan ish asosida keyingi foydali qadam topiladi.

## Loop

**Discover → Prepare → Connect → Create → Build → Launch → Show → Discover**

Maqsad content loop emas, **development loop** yaratish.
