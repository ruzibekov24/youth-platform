# MIYA

## Katta platformadagi roli

MIYA avval alohida concept edi:

> **Muammoni ko‘r. Idea ber. Yechim top. Amalga oshir.**

Youth Platform ichida MIYA **creation va problem-solving layer** bo‘lishi mumkin.

## Core flow

**Problem → Idea → People → Project → Action**

### Problem
Hal qilishga arziydigan muammoni topish.

### Idea
Mumkin bo‘lgan yechimni taklif qilish.

### People
Complementary skillga ega odamlarni topish.

### Project
Idea'ga aniq scope, goal va plan berish.

### Action
Build, test, launch yoki present qilish.

## Mumkin bo‘lgan rollar

- Problem Reporter
- Idea Creator
- Builder
- Designer
- Researcher
- Organizer
- Mentor

Rollar qat’iy bo‘lishi shart emas.

## Nega MIYA kerak?

Execution layer bo‘lmasa, youth platform oddiy opportunity directory yoki idea feedga aylanishi mumkin.

MIYA esa savol beradi:

> **Topgan narsang bilan nima qilasan?**

Hamma user MIYA'dan foydalanishi shart emas. U problem, idea yoki projectga ega user uchun kuchli bo‘lishi kerak.
