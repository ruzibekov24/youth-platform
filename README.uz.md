# Youth Platform — O‘zbekcha

Bu repository uzoq muddatli yoshlar ekotizimi uchun g‘oya, tadqiqot, strategiya va product qarorlarini hujjatlashtirish uchun yaratilgan.

## Hozirgi bosqich

**0-bosqich — Tadqiqot va strategiya.**

Hozircha **app yoki website qurilmayapti**.

## Asosiy g‘oya

Yosh odamni:

**Kashf etish → O‘ylash → Odamlar topish → Qurish → Ishga tushirish → Rivojlanish → Natijani ko‘rsatish**

jarayoni bo‘ylab qo‘llab-quvvatlaydigan yoshlar ekotizimini yaratish.

Loyiha ikki oldingi g‘oyani birlashtiradi:

- **Youth Platform** — imkoniyatlar, ta’lim, community, networking va yoshlar rivoji uchun katta ekotizim.
- **MIYA** — muammodan idea va real projectgacha olib boradigan idea-to-action tizimi.
