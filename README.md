# Youth Platform

> **A digital home for young people.**

## 🇺🇿 O‘zbekcha

Youth Platform — yoshlarning raqamli uyi. Bu shunchaki opportunity topib beradigan servis yoki yana bitta social network emas.

Bu yerda yosh:
- o‘z identity'sini quradi;
- community topadi;
- rivojlanadi;
- idea va projectlar yaratadi;
- odamlar bilan birga ishlaydi;
- opportunitylarda qatnashadi;
- qilgan ishlarini ko‘rsatadi;
- boshqalarga hissa qo‘shadi.

### Asosiy model

**BELONG → GROW → CREATE → CONTRIBUTE**

### MIYA

MIYA — butun platforma emas. U Youth Platform ichidagi **creation va problem-solving layer**:

**Problem → Idea → People → Project → Action**

### Status

**Phase 0 — Vision & Research.**

Hali app qurilmayapti. Avval ecosystem va real muammoni tushunamiz.

---

## 🇬🇧 English

Youth Platform is a **digital home for young people**.

It is not primarily a directory that finds things for users, and it is not simply another social network.

A young person can belong, grow, create, and contribute in one connected environment.

**BELONG → GROW → CREATE → CONTRIBUTE**

MIYA is the creation and problem-solving layer inside the larger platform.

**Problem → Idea → People → Project → Action**

Current status: **Phase 0 — Vision & Research.**

## 🇷🇺 Русский

Youth Platform — это **цифровой дом для молодых людей**.

Это не просто каталог возможностей и не очередная социальная сеть.

Здесь молодой человек может находить своё сообщество, развиваться, создавать проекты и приносить пользу.

**BELONG → GROW → CREATE → CONTRIBUTE**

MIYA — слой создания и решения проблем внутри платформы.

**Проблема → Идея → Люди → Проект → Действие**

Текущий статус: **Фаза 0 — видение и исследование.**
